> **Accept the license terms on first use.** The server blocks all its other tools until you accept the [license terms](https://go.microsoft.com/fwlink/?LinkId=2381247). The `--accepteula` argument does this for you. If you removed the argument, or if you use a different configuration, the agent can report that the license terms are not accepted, or every call to the server fails. In that case, read the license terms. Then tell the agent that you accept them, for example: `I accept the license terms of the Power BI Authoring MCP server`. The agent calls the `accept_eula` tool. Approve that call. The server saves the acceptance in your user profile, so you do this only once.
>
> If the agent tries other tools or scripts to work around the block, for example PowerShell, stop it. Accept the license terms instead.
