**License terms.** From version 1.0, the server requires the acceptance of its [license terms](https://go.microsoft.com/fwlink/?LinkId=2381247) before the first use. There are three ways to accept them:

- The **`--accepteula`** argument, also written `--accept-eula`. The setup of this guide uses it. It applies only to the running process and does not save anything.
- The **`PBI_MODELING_MCP_ACCEPT_EULA=true`** environment variable, in the environment of the server. It applies only to the running process and does not save anything.
- The **`accept_eula`** tool, in the chat. Tell the agent that you accept the license terms, and approve the call. The server saves the acceptance in your user profile, so it applies to the following sessions too.
